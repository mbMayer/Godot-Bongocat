The original [vladelaina/BongoCat](https://github.com/vladelaina/BongoCat) cat as a
Godot editor plugin. It lives in a dock and in a frameless, click-through layer above
every editor workspace, and reacts to your real keyboard and mouse input.


## Install

Requires **Godot 4.7.2.stable**.

Download or install from the Godot
Asset Library, extract it into your project root, then enable **Bongo Cat — Original**
in *Project Settings → Plugins*.

## Use

The dock opens at the bottom; the pinned cat appears in the lower-right corner. All
settings live in the dock: show/hide the pinned cat, corner, mirror, response speed,
flying letters and skin. Input stays passive, so editor shortcuts keep working.
